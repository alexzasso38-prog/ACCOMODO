# Accomodo
Accomodo è un progetto autonomo. Leggere le istruzioni applicabili e rispettare il codice esistente. Lavorare per piccoli passi; aggiornare docs/DECISIONS.md e docs/STATUS.md a ogni milestone. Testare invarianti, isolamento tenant, RLS, pagamenti e webhook su PostgreSQL. Nessun mock spacciato per integrazione reale. Nessuna credenziale in git. Nessun questionario o invio post-visita. Nessun invio, incasso o deploy reale senza configurazione e autorizzazione appropriate. Nessuna modifica distruttiva a database o file non richiesti. Commit piccoli e descrittivi quando autorizzati, senza file estranei; niente push o publish automatici. Riepilogare fatto, mancante e test a ogni milestone.
